# Aayush Shelar - AI Engineering Portfolio

A sleek, modern, and high-performance portfolio website built with Next.js, TailwindCSS, and Framer Motion. Showcasing applied AI systems, multi-agent orchestration, and edge deployment projects.

## Features
- **Premium Dark Theme:** Seamless dark maroon aesthetics with glassmorphic UI cards and radial glow gradients.
- **Responsive Layout:** Perfectly scales from mobile devices to ultra-wide desktop monitors using CSS grid layouts.
- **Smooth Animations:** Integrated with `framer-motion` for scroll-triggered viewport animations and buttery smooth component reveals.
- **Interactive UI:** Micro-interactions on buttons, cards, and links to enhance user engagement.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- Lucide Icons
- TypeScript

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
